# 比布跨境ERP · 客户端系统升级工具

给**比布跨境ERP**客户使用的一键升级软件。客户在本机运行本工具，填写自己系统的 FTP 信息即可把 ERP 系统升级到最新版本，无需在后台等待在线升级、不受虚拟主机执行时间限制、不会因升级锁卡死。

## 快速使用

1. 双击运行 `ERPSystem-Upgrader.exe`（Windows 10/11，无需安装）。
2. 填写您系统的 **FTP 连接信息**（在您的虚拟主机控制面板可查）：
   - FTP 地址、端口（默认 21）、账号、密码
   - 站点目录：ERP 系统在服务器上的根目录，如 `/www/lyc`
3. 填写您系统的**网站访问地址**（升级完成后自动检测网站是否正常），如 `https://zjsongni.com/lyc`
4. 点击 **「连接并检测版本」**：
   - 工具会自动读取您系统的授权信息与当前版本
   - 自动向更新服务器查询最新版本
5. 若发现新版本，点击 **「开始升级」**：
   - 自动下载安装包并校验完整性
   - 自动与服务器上的文件清单做差异对比，只更新有变化的文件
   - **升级前自动把将被覆盖的原文件备份到本机**（`backup_版本_时间` 文件夹）
   - 自动覆盖文件、写入新版本号、回读验证文件哈希、检测网站是否可访问
6. 看到「升级成功」即完成，可正常登录系统。

## 工作原理

本工具绕过 Web 升级器（受虚拟主机单请求执行时间限制、升级锁竞争影响），直接从外部完成升级：

```
检测授权/版本 → 下载安装包(SHA256校验) → 差异对比(只更新变化的文件)
→ 本地备份原文件 → 覆盖升级 → 写版本号 → 哈希回读验证 → 网站探活
```

## 安全说明

- **自动备份**：每个被覆盖的文件升级前都会备份到本机，可随时恢复。
- **保护定制**：若检测到您系统里存在**本地定制文件**（与官方文件清单不一致），工具会**跳过这些文件**，不覆盖您的定制，避免丢失定制功能。
- **数据库迁移**：安装包如包含数据库迁移（SQL），工具会提示并请您联系服务商确认执行，不会擅自改库。
- **不保存密码**：工具不保存您的 FTP 密码，每次启动需重新输入。
- 升级包从官方更新服务器下载并校验 SHA256，防止篡改。

## 常见问题

| 问题 | 处理 |
|---|---|
| 提示"未找到授权文件" | 站点目录填写不正确，请核对 FTP 根目录路径 |
| 提示"授权凭据无效/已到期" | 授权已过期，请联系服务商续期 |
| 提示"本地定制文件跳过" | 属正常保护行为；如需强制覆盖请先自行备份后删除对应文件再升级 |
| 升级中断（网络异常） | 重新运行工具再次升级即可，已覆盖的文件会被再次校验 |
| 网站升级后打不开 | 联系服务商协助排查（升级包已校验、原文件已备份可回滚） |
